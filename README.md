# Calculator - Лабораторна робота 1 (частина 2)
[![Python CI Application](https://github.com/yevheniast01-cmd/trpz-lab-1/actions/workflows/python-app.yml/badge.svg)](https://github.com/yevheniast01-cmd/trpz-lab-1/actions/workflows/python-app.yml)
Простий калькулятор на Python з автоматичною перевіркою коду через GitHub Actions.

## Функціонал
- add(x, y) - додавання двох чисел
- subtract(x, y) - віднімання двох чисел
- автоматична перевірка стилю коду (flake8)
- автоматичний запуск модульних тестів

## Запуск тестів
    python -m unittest test_calculator.py
